# Synthetic FASTQ Test Data

This directory contains 10 artificial paired-end FASTQ samples generated using Python's standard library.

- 10 samples, with R1 and R2 files per sample
- 50 read pairs per sample
- Read length: 100 bases
- Random A/C/G/T sequences and uniform quality characters
- No real participant or research sequencing reads are included

**Limitations:** These random sequences are for software testing only. They are not biologically representative and should not be used to validate real-world sequencing QC performance.
